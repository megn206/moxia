# 墨匣 · 小说灵感卡片

> 一张卡片，一个灵感。从灵感到成书，一站式的小说创作工作台。

**在线使用：** https://megn206.github.io/moxia/

墨匣是一款**纯本地、免安装、免费**的小说创作工具：把一闪而过的灵感变成卡片，再用三模式工作流把零散灵感串成完整的小说。它没有后台服务器，你的数据全部存在自己的设备里，隐私安全。

## 三模式工作流

墨匣顶部有一个 **模式切换器**，三种模式覆盖小说创作全流程：

```
💡 灵感  →  ✍ 写作  →  🕸 脉络
 随手记      埋头写       梳理故事
```

| 模式 | 用途 |
|---|---|
| 💡 **灵感** | 默认主页。卡片网格，随手记灵感、人物、设定、对话片段 |
| ✍ **写作** | 沉浸式写书。按章节组织正文，打字机模式专注码字，自动保存 |
| 🕸 **脉络** | 可视化剧情。时间线拖卡片、人物关系、伏笔追踪、世界设定图 |

三种模式共用同一套卡片数据，在写作模式里写的章节，在灵感模式里能看到，在脉络模式里能拖进时间线。

## 快速上手（30 秒）

1. 打开页面，点击工具栏 **✚ 新建灵感**；
2. 填写内容：标题（可选）、分类、正文，可附加图片、标签、时间标记；
3. 点保存，卡片出现在网格里；
4. 点卡片可再次编辑；卡片右上角 ☆ 置顶、✕ 删除（删除进回收站，可恢复）；
5. 顶部搜索框输入关键词，实时筛选标题、内容、标签。

**开始写小说**：切到 ✍ 写作模式 → 选一张章节卡片开始写，或用 🧩 功能里的「章节模板」一键生成章节骨架。

## 💡 灵感模式

### 卡片系统

| 操作 | 说明 |
|---|---|
| 新建卡片 | 工具栏 **✚ 新建灵感** |
| 随机抽一张 | 工具栏 **🎲 随机抽一张**，卡文时随机回看旧灵感 |
| 编辑卡片 | 点击卡片，弹出编辑窗口 |
| 置顶卡片 | 卡片右上角 ☆ / ★ |
| 删除卡片 | 卡片右上角 ✕，先进回收站，可恢复 |
| 搜索 | 顶部搜索框，匹配标题、内容、标签，实时筛选 |
| 拖动排序 | 按住卡片拖动可调整位置 |
| 快捷键 | `N` 新建卡片；`Ctrl+K` 唤起搜索 |

**卡片可填写的字段：**

- **标题**（最多 60 字，可选）
- **分类**（下拉选择，可自定义）
- **正文**（灵感主体：人物、对话、画面、设定……）
- **图片**（最多 9 张；图片压缩后与卡片一起保存在本机浏览器里；支持文件选择和 Ctrl+V 粘贴截图）
- **标签**（逗号分隔，如 `反派,伏笔,高潮`）
- **时间标记**（可选，如 `第3章` / `午后` / `某年某月`，用于剧情时间线）
- **章节信息**（卷号 / 章号 / 章名 / 写作状态：草稿/修改中/完成）

编辑时内容会**自动保存草稿**，误点关闭不会丢。

### 人物档案卡

当卡片分类选「人物」时，编辑窗口会出现专属档案栏：

- **年龄 / 性格 / 外貌 / 动机 / 关系** 五个字段
- 保存后卡片上自动显示 🎂💬👀🔥🤝 角标
- 在写作模式里写这个人物出场的章节时，档案自动可调

### 分类设置

打开 **🧩 功能 → 🏷 分类设置**：

- **改名称**：会同步到已有卡片；
- **改颜色**：选择色块，卡片标记随之变色；
- **改形状**：圆形 / 方形等形状切换；
- **增加分类**：面板内有「增加」按钮，可添加新分类；
- **删除分类**：删除后该分类下的卡片归入默认分类。

## ✍ 写作模式

切到 ✍ 写作模式，进入沉浸式写书界面：

### 写作界面

- **顶栏**：当前书名 / 选卡 / 新建 / 上一张 / 下一张 / 保存
- **正文区**：大字号宽行距，专注码字
- **字数统计**：顶栏实时显示已写字数

### 写作辅助功能

| 功能 | 说明 |
|---|---|
| **⌨ 打字机模式** | 开启后正文行距加大、工具栏自动淡出，像真正的打字机一样专注当前行 |
| **🔓 草稿锁定** | 锁定后正文只读，防止手滑误改；点 🔒 解锁继续写 |
| **🕘 版本历史** | 每次保存自动留快照（最多 12 版），可随时查看历史版本、恢复到任意一版 |
| **自动保存** | 每 45 秒静默保存一次，不弹窗；写长文不怕闪退丢稿 |
| **Shift+Enter 保存** | 写作时按 Shift+回车快速保存当前章节 |

### 章节管理

- **📚 目录树**：左侧按 卷 → 章 排列，点章节名直接跳转
- **章节工具**：合并两张卡、按空行拆分一章为多章（章号自动顺延）
- **章节模板**：一键生成套路骨架——三幕式、英雄之旅 12 步、起承转合、单章闭环
- **章节状态**：草稿 / 修改中 / 完成，目录树里彩色标记

### 写作统计

**🧩 功能 → 写作统计**：

- 全书总字数 / 平均每篇字数 / 未编章字数
- 各章字数排行（按卷→章排列）
- 近 30 天每日写作字数柱状图

## 墨匣云阁（同步/备份）

工具栏点 **🏮 墨匣云阁** 打开：

- **📤 导出备份**：全部卡片下载为 JSON

- **强制重传 / 断开同步**

## 数据与隐私

- **默认零上传**：所有卡片、图片、便签、设置都保存在**当前设备的浏览器本地**
- **云端同步是可选项**：不配置就永远是本地模式
- **仓库公开但无数据**：GitHub 仓库里只有程序代码
- 删卡片先进回收站，误删可恢复

1. 我更新功能后，新文件会放到发布包文件夹；
2. 把新版 `index.html` 和 `sw.js` 覆盖到 GitHub 仓库；

4. 刷新页面即用新版（sw.js 已改为网络优先策略）。

## 常见问题

**Q：图片存哪里？会占很多空间吗？**
A：图片压缩后存在浏览器本地。删除卡片后图片随之删除；上传视频/壁纸时自动压缩。

**Q：OCR 第一次用很慢？**
A：首次需联网下载约 20MB 中文识别引擎，之后离线可用。

**Q：换浏览器数据会丢吗？**
A：数据存在浏览器里。重要内容建议定期导出备份，或配置云端同步。

**Q：写作模式和灵感模式的数据是分开的吗？**
A：完全共用同一套卡片。写作模式里写的章节，本质上就是有章号信息的卡片，在灵感模式、脉络模式里都能看到和编辑。

## 技术说明

- **纯前端**：单文件 HTML + CSS + JavaScript，无后端依赖
- **托管**：GitHub Pages（HTTPS）
- **PWA**：manifest + Service Worker，支持安装与离线
- **OCR**：Tesseract.js（中文简体），本地识别
- **同步（可选）**：Supabase
- **三模式**：灵感网格 / 沉浸式写作 / 脉络可视化，共用同一数据层
