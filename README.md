# 墨匣 · Moxia

> 把灵感养成故事的小说创作工作台 —— 灵感卡片 · 写作台 · 剧情脉络，三模式一体联动。

墨匣是一款纯前端、单文件的小说创作工具：灵感卡片帮你随手捕捉脑洞，写作台让章节落笔成书，剧情脉络把人物与伏笔织成故事网。所有数据保存在本地浏览器，支持云端同步与灵感广场分享。

- **在线版**：<https://megn206.github.io/moxia/>
- **源码仓库**：<https://github.com/megn206/moxia>

---

## 快速开始

1. 打开在线版（推荐，可直连云同步）或本地双击 `index.html`；
2. 在**灵感模式**随手新建卡片，记录任何脑洞；
3. 切到**写作模式**创建作品与章节，正文自动保存；
4. 切到**脉络模式**把卡片连成剧情网，把章节放进时间轴；
5. 需要多设备同步时，打开「云阁」填入你的 Supabase 配置。

> 本地 `file://` 打开时，浏览器安全策略会阻止直连云端；要用云同步请打开在线版。

## 三大模式

墨匣的三个模式平级共存、数据互相独立，但可以通过引用与拖拽互相借用。

### 🧠 灵感模式
- 卡片式灵感收集：文本、图片、分类、便签、时间轴
- 卡片类型：**灵感卡 / 人物卡 / 伏笔卡**（人物卡、伏笔卡有专属编辑界面与展示样式）
- 分类可增删改（改名称会同步到已有卡片），颜色与形状自定义
- 卡片排序：默认 / 随机 / 高亮回顾；搜索高亮命中
- 关键词联想、灵感接龙（AI 助手栏）
- 卡片引用他人灵感（拖卡到写作/脉络切换按钮即可插入）

### ✍️ 写作模式（写作台）
- 书册树：作品 → 卷 → 章节，三级结构
- 正文编辑器：自动保存、字数/目标统计、专注模式、阅读预览、导出 TXT
- 右侧写作助手：相关灵感、人物/伏笔速查、素材库
- 新章节 / 新卷快捷按钮；章节卡片可拖入脉络时间轴

### 🕸 脉络模式
- 画布节点：灵感卡片、人物卡、伏笔卡、写作章节节点（橙色）全部可入画
- 连线类型：关联 / 伏笔 / 人物关系 / 人物出场 / 对照 / 配角
- 长按拖动连线，点击节点查看详情；横向时间轴模式整理剧情
- 节点显示标题前 3 字，无标题显示内容前 3 字

## 跨模式联动（本次新增）

写作台与灵感、脉络全面打通：

| 功能 | 入口 | 说明 |
|---|---|---|
| 📇 素材库 | 写作台功能区 | 本册全部灵感/人物/伏笔卡，点击插入 `[@卡名]` 引用 |
| 🎯 大纲转章 | 写作台功能区 | 把情节/大纲/世界观卡一键生成章节并挂接素材 |
| 👥 人物出场 | 写作台功能区 | 统计当前章节提到的人物卡次数，可插入引用 |
| 🔍 全局搜索 | 写作台功能区 | 同时搜章节正文、灵感、人物、伏笔，章节一键跳转、卡片插入引用 |
| 拖卡入章 | 从灵感区拖卡到写作台 | 拖入编辑器自动插入引用标记并记入素材 |
| 伏笔回写 | 自动 | 正文写 `【伏笔：xxx】`，自动记入对应伏笔卡 |
| 章节节点 | 脉络模式 | 写作台章节自动出现在脉络画布，可连边、可拖入时间轴 |

正文中 `[@id:名字]` 形式的引用，在编辑时会直接渲染为可悬停的《名字》引用小卡（悬停或点击即可查看对应灵感卡的分类、标签与内容），保存后自动还原为存储标记，阅读预览同样渲染为小卡。

## 云阁 · 云同步

- 端到端加密：数据用你的口令加密后上传，服务端只见密文
- 同步内容：灵感卡、分类设置、写作台书册（作品/卷/章节/正文）
- 云备份：云端快照与导出/导入备份均完整包含写作台书册，可一键恢复
- 冲突处理：按更新时间合并，删除有墓碑标记
- 自动暂停：无更新内容时自动停止同步，不空转
- 配置方式：打开「云阁」→ 填 Supabase URL / anon key / 房间名 / 口令

## 妆阁 · 主题美化

- 主题系列：水墨古韵（山水/朱砂/青黛等）、科幻、赛博、白日（明亮系）等
- 自定义模式：调色盘 + 壁纸图案 + 透明度 + 渐变色，可保存预设
- 卡片美化：光晕、透明拉条、渐变封面、hover 动效
- 自定义壁纸：可上传图片/视频作为背景播放

## 灵感广场

- 把灵感卡发布到公共广场，浏览/收藏/删除他人分享的灵感
- 广场数据独立于本地，不参与本地同步

## 数据与存储

| 数据 | 位置 |
|---|---|
| 灵感卡 | IndexedDB `idea-cards-sync`（含 localStorage 备份） |
| 分类/主题/设置 | localStorage `novel-idea-cards-v1*`、`moxia-*` |
| 写作台书册 | localStorage `moxia-wb-v1` |
| 云端 | Supabase（端到端加密） |

## 技术说明

- 纯前端单文件 HTML，无构建、无依赖，浏览器直接运行
- 数据默认存本地，不上传任何第三方；云同步需用户自行配置 Supabase
- 支持 PWA 化 / GitHub Pages 部署（本仓库即演示）
- 兼容 Chrome / Edge；旧浏览器自动降级半透明背景
