# 墨匣 · 小说灵感卡片
> 一张卡片，一个灵感。从灵感到成书，一站式的小说创作工作台。

**在线使用：** https://megn206.github.io/moxia/

墨匣是一款**纯本地、免安装、免费**的小说创作工具：把一闪而过的灵感变成卡片，再用「灵感 + 脉络」双模式把零散灵感串成完整的故事。它没有后台服务器，你的数据默认全部存在自己的设备里，隐私安全；也可以选配云同步，手机电脑随时互通。

## 快速上手（30 秒）
1. 打开页面，按 `N` 或点功能区 **✚ 新建**；
2. 填写内容：标题（可选）、分类、正文，可附加图片、标签、时间标记、日期；
3. 按 `Shift+Enter` 或点保存，卡片出现在网格里；
4. 点卡片可再次编辑；方向键选中卡片后 `Delete` 删除（进回收站，可恢复）；
5. 顶部搜索框输入关键词，实时筛选标题、内容、标签；搜索框右侧可拖拽调整宽度。

**开始写小说**：给卡片填上「卷号 / 章号 / 章名」，切到 📖 章节目录查看结构，用 📦 导出成书生成完整 TXT。

## 💡 灵感模式
### 卡片系统
| 操作 | 说明 |
|---|---|
| 新建卡片 | `N` 键，或功能区 **✚ 新建** |
| 随机抽一张 | 功能区 **🎲**，卡文时随机回看旧灵感 |
| 编辑卡片 | 点击卡片，弹出编辑窗口 |
| 置顶卡片 | 卡片右上角 ☆ / ★ |
| 删除卡片 | 方向键选中后按 `Delete`，或卡片 ✕（先进回收站，可恢复） |
| 搜索 | 顶部搜索框，匹配标题、内容、标签，实时筛选 |
| 拖动排序 | 按住卡片拖动可调整位置 |

**卡片可填写的字段：**
- **标题**（最多 60 字，可选）
- **分类**（下拉选择，可自定义名称/颜色/形状）
- **正文**（灵感主体：人物、对话、画面、设定……）
- **图片**（最多 9 张；支持文件选择、Ctrl+V 粘贴截图；主页面只显示"有图"角标，点击角标展开大图，再点收起）
- **标签**（逗号分隔，如 `反派,伏笔,高潮`）
- **日期 / 时间标记**（如 `2026-03-01` / `午后`，用于脉络大事记和时间线）
- **章节信息**（卷号 / 章号 / 章名 / 写作状态：草稿/修改中/完成）
编辑时内容会**自动保存草稿**，误点关闭不会丢。

### 人物卡 & 伏笔卡
新建卡片时可选**专用类型**，有专属编辑界面和卡片样式：
- **👤 人物卡**（粉色系）：年龄 / 性格 / 外貌 / 动机 / 关系 专属档案栏，卡片带圆形头像角标
- **🧵 伏笔卡**（紫色系）：类型（悬念/铺垫/暗示/反转）/ 埋设点 / 回收计划 / 状态，卡片带进度条，随时知道哪些坑还没填

### 分类设置
功能区 → 🏷 分类设置：
- **改名称**：会同步到已有卡片；
- **改颜色 / 改形状**：卡片标记随之变化；
- **增加 / 删除分类**：面板内可增删。

## 🕸 脉络模式
切到 🕸 脉络，把零散灵感变成完整的故事结构。灵感模式与脉络模式**平级独立**，数据互不相通，但可以把灵感卡片**拖到模式切换按钮**上，一键复制/引用到脉络里继续用。

| 功能 | 说明 |
|---|---|
| **⏱ 剧情时间线** | 一条横向时间线（默认隐藏，按按钮展开），把卡片拖进来排列剧情顺序，拖动可调整位置 |
| **🕸 人物关系图** | 记录并可视化人物之间的关系；**长按拖动卡片即可连出关系线** |
| **🧵 伏笔追踪** | 记录「埋了什么伏笔、在哪埋的、计划在哪回收」，防止挖坑不填 |
| **🗓 大事记** | 有日期/时间标记的卡片自动排成故事年表 |
| **✨ AI 理解** | 一键让 AI 分析整张脉络图：剧情梗概、人物关系、伏笔追踪、逻辑风险、创作建议 |

脉络节点自带专属编辑器，编辑后保存仍是圆形节点，不影响整页布局。

## ✨ AI 助手
**首次使用**：功能区 → 🧩 功能 → ✨ AI 设置，选择接入方式：
- **DeepSeek 官方 API**（填 API Key）
- **豆包 / 火山方舟**（填 API Key）

配置好之后，AI 能力全部可用：

**编辑器内 AI 助手**（编辑卡片时）：
| 按钮 | 说明 |
|---|---|
| 🎯 **按我的习惯补完** | 粘贴/上传一张图（或填好部分内容），AI 参考你过去写过的卡片风格，替你把整张卡补完 |
| **续写** | 接着当前内容往下写 |
| **扩写** | 把简略内容扩成完整段落 |
| **润色** | 优化措辞、通顺语句 |

**脉络 AI 理解**：脉络顶栏 ✨ 理解，一键生成剧情梗概 / 人物关系 / 伏笔追踪 / 逻辑与风险 / 创作建议。

## ⌨ 纯键盘操作
不用鼠标也能畅快操作，全套快捷键：

| 按键 | 功能 |
|---|---|
| `Tab` | 进入功能区导航（按钮间循环移动） |
| `↑ ↓ ← →` | 卡片网格移动焦点 / 功能区选按钮 / 编辑器选控件 |
| `Enter` | 打开焦点卡片 / 触发按钮 / 进入输入框编辑 / 正文换行 |
| `Esc` | 退出编辑态 → 退出控件选择 → 关闭面板，逐层返回 |
| `Delete` | 删除焦点卡片（进回收站） |
| `N` | 新建卡片 |
| `Ctrl+K` | 聚焦搜索框 |
| `Shift+Enter` | 编辑器内快速保存 |

**编辑器双态模式**：编辑窗口打开后默认是**浏览态**——方向键在标题、内容、标签、按钮间移动（橙色高亮），按 `Enter` 进入输入框开始打字（此时方向键全部用于移动光标、选择位置）；按 `Esc` 退出编辑态，回到控件选择；再按 `Esc` 关闭编辑器。

## 数据与隐私
- **默认零上传**：所有卡片、图片、便签、设置都保存在**当前设备的浏览器本地**
- **云端同步是可选项**：不配置就永远是本地模式
- **仓库公开但无数据**：GitHub 仓库里只有程序代码
- 删卡片先进回收站，误删可恢复
- 同步口令（若设置）忘了则云端数据无法恢复；「导出备份」永远是最终保险

## 常见问题
**Q：图片存哪里？会占很多空间吗？**
A：图片压缩后存在浏览器本地。删除卡片后图片随之删除；上传视频/壁纸时自动压缩。

**Q：OCR 第一次用很慢？**
A：首次需联网下载约 20MB 中文识别引擎，之后离线可用。

**Q：换浏览器数据会丢吗？**
A：数据存在浏览器里。重要内容建议定期导出备份，或配置云端同步。

**Q：灵感模式和脉络模式的数据是分开的吗？**
A：是的，两边数据独立。想互通的话，把灵感卡片拖到「脉络」模式按钮上，会自动复制/引用到脉络里。

**Q：AI 需要付费吗？**
A：本地 Ollama 完全免费离线；DeepSeek / 豆包按官方 API 计费，用量很小。

## 技术说明
- **纯前端**：单文件 HTML + CSS + JavaScript，无后端依赖
- **托管**：GitHub Pages（HTTPS）
- **PWA**：manifest + Service Worker，支持安装与离线
- **OCR**：Tesseract.js（中文简体），本地识别
- **AI**：DeepSeek / 火山方舟（豆包）/ 本地 Ollama，OpenAI 兼容协议
- **同步（可选）**：Supabase
- **双模式**：灵感网格 / 脉络可视化，独立数据层，可互相拖拽引用
