**在线使用：** https://megn206.github.io/moxia/

## 快速上手（30 秒）

1. 打开页面，点击右下角 **＋** 新建一张卡片；
2. 填写内容：标题（可选）、分类、正文，可附加图片、标签、时间标记；
3. 点保存，卡片出现在网格里；
4. 点卡片可再次编辑；卡片右上角 ☆ 置顶、✕ 删除（删除进回收站，可恢复）；
5. 顶部搜索框输入关键词，实时筛选标题、内容、标签。

## 功能详解

### 卡片系统

| 操作 | 说明 |
|---|---|
| 新建卡片 | 右下角 **＋** 按钮 |
| 随机抽一张 | 功能区「🎲 随机抽一张」，卡文时随机回看旧灵感 |
| 编辑卡片 | 点击卡片，弹出编辑窗口 |
| 置顶卡片 | 卡片右上角 ☆ / ★ |
| 删除卡片 | 卡片右上角 ✕，先进回收站，可恢复 |
| 搜索 | 顶部搜索框，匹配标题、内容、标签，实时筛选 |
| 拖动排序 | 按住卡片拖动可调整位置 |

**卡片可填写的字段：**

- **标题**（最多 60 字，可选）
- **分类**（下拉选择，可自定义，见下文）
- **正文**（灵感主体：人物、对话、画面、设定……）
- **图片**（最多 9 张；图片会压缩后与卡片一起保存在本机浏览器里；支持文件选择和 Ctrl+V 粘贴截图）
- **标签**（逗号分隔，如 `反派,伏笔,高潮`）
- **时间标记**（可选，如 `第3章` / `午后` / `某年某月`，用于剧情时间线）

编辑时内容会**自动保存草稿**，误点关闭不会丢。

### 分类设置

功能区点 **🏷 分类** 打开分类设置面板：

- **改名称**：会同步到已有卡片；
- **改颜色**：选择色块，卡片标记随之变色；
- **改形状**：圆形 / 方形等形状切换；
- **增加分类**：面板内有「增加」按钮，可添加新分类；
- **删除分类**：删除后该分类下的卡片归入默认分类（建议先看分类下有没有卡）。

### 功能区工具箱（11 个工具）

功能区点 **🧩 功能** 打开工具箱，后续新功能都会加在这里：

| 工具 | 说明 |
|---|---|
| 📷 **识别图片文字（OCR）** | 提取图片中的文字。选文件或 **Ctrl+V 直接粘贴截图**；首次使用需联网下载识别引擎（中文包约 20MB），之后可离线使用 |
| 📖 **朗读卡片** | 语音朗读全部卡片的标题和正文，检查语感；再点一次停止 |
| 💡 **灵感触发器** | 随机组合「人物 × 场景 × 冲突」，卡文时摇一摇找灵感 |
| 🔢 **字数统计** | 统计全部卡片总字数与各分类字数 |
| 📄 **导出 Markdown** | 把全部卡片导出为一个 Markdown 文档，方便整理、备份、迁移 |
| 🧵 **伏笔追踪器** | 记录「埋了什么伏笔、在哪埋的、计划在哪回收」，防止挖坑不填 |
| 🕸 **人物关系图** | 记录并可视化人物之间的关系（师徒 / 敌对 / 恋人……），角色多了也不乱 |
| ✒️ **随机起名器** | 按风格批量生成角色名：古风 / 西幻 / 现代 / 异世界，点击名字即复制 |
| 📋 **卡片模板** | 人物 / 场景 / 世界观 / 冲突 / 情节 模板，一键打开新建卡片并预填结构 |
| 🗑 **灵感回收站** | 误删的卡片在这里一键恢复；可永久删除或清空 |
| ⏱ **剧情时间线** | 按时间标记排列剧情卡片，防止时间线崩坏 |

### 热点榜单

右上角 **🔥 热点** 打开热点面板：

- **切换平台**：微博 / 知乎 / 抖音 / 头条，点标签即切换；
- **搜索**：面板内有搜索框，可搜索当前榜单关键词；
- 数据来自公开热点接口，5 分钟缓存，随时刷新。

### 便签贴纸

功能区点 **🗒 便签** 添加便利贴：

- **双击编辑**文字内容；
- 右上角 **🎨 换颜色**、**◧ 换形状**；
- 可**拖动**到任意位置；
- 右上角 ✕ 删除。

### 主题切换

功能区顶部有色点切换主题，共 5 种：

| 主题 | 说明 |
|---|---|
| 跟随系统 | 自动匹配系统的深色/浅色模式 |
| 纸墨 | 米白暖色（默认） |
| 夜幕 | 深棕暗色，适合夜晚 |
| 黛蓝 | 深蓝墨色 |
| 青瓷 | 青绿浅色 |

### 云端同步（可选）

默认**纯本地模式**（数据只在当前设备）。如需多设备同步（如电脑 ↔ 手机），功能区点「本地模式」按钮进入同步设置：

1. 在 [supabase.com](https://supabase.com) 免费注册并新建一个项目（按配套的《云端同步配置指南》操作）；
2. 把项目的 **URL** 和 **anon key** 填进墨匣；
3. 填写**房间名**（随便起，如 `novel-me`），各设备填一样的即可互通；
4. 可选设置**同步口令**：填了则数据加密传输，各设备必须一致。

同步只发生在你配置的 Supabase 项目里，第三方不可见。

## 数据与隐私

- **默认零上传**：所有卡片、图片、便签、设置都保存在**当前设备的浏览器本地**（localStorage / IndexedDB）；
- **云端同步是可选项**：不配置就永远是本地模式；
- **仓库公开但无数据**：GitHub 仓库里只有程序代码，不包含你的任何创作内容；
- 删卡片先进回收站，误删可恢复；回收站可永久删除。

## 手机当 App 用（PWA）

墨匣是 PWA（渐进式网页应用），手机可以像 App 一样使用：

1. 手机浏览器打开 https://megn206.github.io/moxia/ ；
2. 菜单里选「**添加到主屏幕 / 添加到桌面**」；
3. 桌面出现「墨匣」图标，点开**全屏运行**，体验与 App 一致；
4. 支持**离线打开**（断网也能看已缓存的页面）。

电脑 Chrome/Edge 同样支持「安装应用」，获得独立窗口。

> 提示：手机端与电脑端数据默认各自独立，想互通请配置上面的云端同步。

1. 我更新功能后，新文件会放到发布包文件夹；
2. 打开 https://github.com/megn206/moxia → **Add file** → 拖入新文件覆盖 → **Commit changes**；

## 常见问题

**Q：图片存哪里？会占用很多空间吗？**
A：图片压缩后存在浏览器本地（IndexedDB）。删除卡片后图片随之删除；回收站清空会彻底释放空间。

**Q：OCR 第一次用很慢 / 失败？**
A：首次使用需联网下载约 20MB 的中文识别引擎，请保持网络通畅，稍等片刻；之后识别走本地引擎，可离线。

**Q：换了浏览器 / 清了浏览器缓存，数据会丢吗？**
A：数据存在浏览器里，清除该网站缓存/数据会丢失。重要内容建议定期用「📄 导出 Markdown」备份，或配置云端同步。

**Q：手机上能同步电脑的数据吗？**
A：配置云端同步后即可互通（见上文「云端同步」）。

**Q：功能面板被卡片挡住了怎么办？**
A：关闭面板或收起功能区即可；面板为浮层设计，不会影响卡片本身。

## 技术说明

- **纯前端**：单文件 HTML + CSS + JavaScript，无后端、无数据库依赖；
- **托管**：GitHub Pages（HTTPS，全球访问）；
- **PWA**：manifest + Service Worker，支持安装与离线缓存；
- **OCR**：Tesseract.js（中文简体），识别在本地完成；
- **同步（可选）**：Supabase（PostgreSQL 云数据库）。
