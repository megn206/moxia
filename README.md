# 墨匣 · 小说灵感卡片

> 一张卡片，一个灵感。为小说创作者打造的灵感收集与管理工具。

**在线使用：** https://megn206.github.io/moxia/

墨匣是一款**纯本地、免安装、免费**的小说创作灵感工具：把一闪而过的灵感、人物设定、对话片段、伏笔安排都变成卡片，随手记、随时找、分类管。数据默认全部存在自己的设备里，隐私安全；也可以开启可选云端同步，多设备互通。

## 快速上手（30 秒）

1. 打开页面，点击右下角 **＋** 新建一张卡片；
2. 填写内容：标题（可选）、分类、正文，可附加图片、标签、时间标记；
3. 点保存，卡片出现在网格里；
4. 点卡片可再次编辑；卡片右上角 ☆ 置顶、✕ 删除（删除进回收站，可恢复）、🖼 导出图片、🔗 剧情串链；
5. 顶部搜索框输入关键词，实时筛选标题、内容、标签。

## 功能详解

### 卡片系统

| 操作 | 说明 |
|---|---|
| 新建卡片 | 右下角 **＋** 按钮 |
| 随机抽一张 | 功能区「🎲 随机抽一张」，卡文时随机回看旧灵感 |
| 编辑卡片 | 点击卡片，弹出编辑窗口 |
| 置顶卡片 | 卡片右上角 ☆ / ★ |
| 删除卡片 | 卡片右上角 ✕，先进回收站，可恢复 |
| 导出图片 | 卡片右上角 🖼，一键导出精美 PNG 长图（分类色条 + 书册名 + 日期水印） |
| 剧情串链 | 卡片右上角 🔗，与另一张卡片建立双向关联，点击标签可跳转 |
| 搜索 | 顶部搜索框，匹配标题、内容、标签，实时筛选 |
| 拖动排序 | 按住卡片拖动可调整位置 |

**卡片可填写的字段：**

- **标题**（最多 60 字，可选）
- **分类**（下拉选择，可自定义，见下文）
- **正文**（灵感主体：人物、对话、画面、设定……）
- **图片**（最多 9 张；图片会压缩后与卡片一起保存在本机浏览器里；支持文件选择和 Ctrl+V 粘贴截图）
- **标签**（逗号分隔，如 `反派,伏笔,高潮`）
- **时间标记**（可选，如 `第3章` / `午后` / `某年某月`，用于剧情时间线）

编辑时内容会**自动保存草稿**，误点关闭不会丢。

### 分类设置

功能区点 **🏷 分类** 打开分类设置面板：

- **改名称**：会同步到已有卡片；
- **改颜色**：选择色块，卡片标记随之变色；
- **改形状**：圆形 / 方形等形状切换；
- **增加分类**：面板内有「增加」按钮，可添加新分类；
- **删除分类**：删除后该分类下的卡片归入默认分类（建议先看分类下有没有卡）。

### 多作品书册

顶部 **📚 书册** 打开书册管理面板：

- **新建 / 切换 / 重命名 / 删除**书册，一本书一个书册，互不干扰；
- 卡片归属当前书册，切换书册后只显示该书册的卡片；
- **删除书册不会丢卡片**（自动移回默认册）；
- 卡片数据随云端同步整卡加密上传，兼容旧数据（自动归入默认册）。

### 灵感广场

墨匣专属的**公共灵感分享区**（与主应用互跳，入口在右上角 📤 或 https://megn206.github.io/moxia/plaza.html）：

- **发布**：把自己的灵感分享到广场（可自定义昵称、标题、标签、分类）；
- **浏览**：贴吧列表模式 + 翻卡（短视频）模式，滚轮 / 滑动切换；
- **搜索**：按标题、内容、标签关键词搜索广场灵感；
- **删除**：自己的卡片随时可删（列表 / 翻卡 / 详情三处入口）；
- **屏蔽**：不想看谁的内容就屏蔽，其内容立即消失，可在 🛡 管理 解除；
- **举报**：违规内容一键举报（选原因），记录留痕可导出；
- **发布自检**：发布时自动拦截明显违规内容（广告 / 赌博 / 诈骗 / 露骨色情）；
- **自动下架**：同一内容被多人举报达到阈值后，自动从广场下架（需按 Supabase 配套 SQL 建举报表）。

### 云端同步（可选）

默认**纯本地模式**（数据只在当前设备）。如需多设备同步（如电脑 ↔ 手机），功能区点「本地模式」按钮进入同步设置：

1. 在 [supabase.com](https://supabase.com) 免费注册并新建一个项目（按配套的《云端同步配置指南》操作）；
2. 把项目的 **URL** 和 **anon key** 填进墨匣；
3. 填写**房间名**（随便起，如 `novel-me`），各设备填一样的即可互通；
4. 可选设置**同步口令**：填了则数据加密传输，各设备必须一致。

同步只发生在你配置的 Supabase 项目里，第三方不可见。

## 数据与隐私

- **默认零上传**：所有卡片、图片、便签、设置都保存在**当前设备的浏览器本地**（localStorage / IndexedDB）；
- **云端同步是可选项**：不配置就永远是本地模式；
- **仓库公开但无数据**：GitHub 仓库里只有程序代码，不包含你的任何创作内容；
- 删卡片先进回收站，误删可恢复；回收站可永久删除。

## 手机当 App 用（PWA）

墨匣是 PWA（渐进式网页应用），手机可以像 App 一样使用：

1. 手机浏览器打开 https://megn206.github.io/moxia/ ；
2. 菜单里选「**添加到主屏幕 / 添加到桌面**」；
3. 桌面出现「墨匣」图标，点开**全屏运行**，体验与 App 一致；
4. 支持**离线打开**（断网也能看已缓存的页面）。

电脑 Chrome/Edge 同样支持「安装应用」，获得独立窗口。

> 提示：手机端与电脑端数据默认各自独立，想互通请配置上面的云端同步。

## 常见问题

**Q：图片存哪里？会占用很多空间吗？**
A：图片压缩后存在浏览器本地（IndexedDB）。删除卡片后图片随之删除；回收站清空会彻底释放空间。

**Q：OCR 第一次用很慢 / 失败？**
A：首次使用需联网下载约 20MB 的中文识别引擎，请保持网络通畅，稍等片刻；之后识别走本地引擎，可离线。

**Q：换了浏览器 / 清了浏览器缓存，数据会丢吗？**
A：数据存在浏览器里，清除该网站缓存/数据会丢失。重要内容建议定期用「📄 导出 Markdown」备份，或配置云端同步。

**Q：手机上能同步电脑的数据吗？**
A：配置云端同步后即可互通（见上文「云端同步」）。

**Q：AI 续写/润色怎么用？**
A：编辑任意卡片 → 底部 AI 助手行 → 续写 / 扩写 / 润色。首次使用先到 ⋯ → ✨ AI 设置 填入 DeepSeek API Key。

**Q：多本书的卡片会不会混在一起？**
A：不会。用 📚 书册 分册管理，切换书册只显示当前书册的卡片；删除书册卡片自动移回默认册。

**Q：广场上删不掉别人的内容？**
A：广场删除只对自己的卡片开放（防止误删他人）；看到违规内容请用「屏蔽」或「举报」。

**Q：功能面板被卡片挡住了怎么办？**
A：关闭面板或收起功能区即可；面板为浮层设计，不会影响卡片本身。

## 技术说明

- **纯前端**：单文件 HTML + CSS + JavaScript，无后端、无数据库依赖；
- **托管**：GitHub Pages（HTTPS，全球访问）；
- **PWA**：manifest + Service Worker，支持安装与离线缓存；
- **OCR**：Tesseract.js（中文简体），识别在本地完成；
- **AI 助手**：DeepSeek API（密钥仅存本机）；
- **广场**：Supabase 公共表 + RPC（发布 / 删除），屏蔽与举报记录本地留存，举报自动下架需配套 SQL；
- **同步（可选）**：Supabase（PostgreSQL 云数据库）。
