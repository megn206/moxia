# 墨匣 · 小说灵感卡片

> 一张卡片，一个灵感。为小说创作者打造的灵感收集与管理工具。

**在线使用：** https://megn206.github.io/moxia/

墨匣是一款**纯本地、免安装、免费**的小说创作灵感工具：把一闪而过的灵感、人物设定、对话片段、伏笔安排都变成卡片，随手记、随时找、分类管。它没有后台服务器，你的数据全部存在自己的设备里，隐私安全。

## 快速上手（30 秒）

1. 打开页面，点击工具栏 **✚ 新建灵感**；
2. 填写内容：标题（可选）、分类、正文，可附加图片、标签、时间标记；
3. 点保存，卡片出现在网格里；
4. 点卡片可再次编辑；卡片右上角 ☆ 置顶、✕ 删除（删除进回收站，可恢复）；
5. 顶部搜索框输入关键词，实时筛选标题、内容、标签。

## 功能详解

### 卡片系统

| 操作 | 说明 |
|---|---|
| 新建卡片 | 工具栏 **✚ 新建灵感** |
| 随机抽一张 | 工具栏 **🎲 随机抽一张**，卡文时随机回看旧灵感 |
| 编辑卡片 | 点击卡片，弹出编辑窗口 |
| 置顶卡片 | 卡片右上角 ☆ / ★ |
| 删除卡片 | 卡片右上角 ✕，先进回收站，可恢复 |
| 搜索 | 顶部搜索框，匹配标题、内容、标签，实时筛选 |
| 拖动排序 | 按住卡片拖动可调整位置 |
| 快捷键 | `N` 新建卡片；`Ctrl+K` 唤起搜索 |

**卡片可填写的字段：**

- **标题**（最多 60 字，可选）
- **分类**（下拉选择，可自定义）
- **正文**（灵感主体：人物、对话、画面、设定……）
- **图片**（最多 9 张；图片压缩后与卡片一起保存在本机浏览器里；支持文件选择和 Ctrl+V 粘贴截图）
- **标签**（逗号分隔，如 `反派,伏笔,高潮`）
- **时间标记**（可选，如 `第3章` / `午后` / `某年某月`，用于剧情时间线）

编辑时内容会**自动保存草稿**，误点关闭不会丢。

### 分类设置

打开 **🧩 功能 → 🏷 分类设置**：

- **改名称**：会同步到已有卡片；
- **改颜色**：选择色块，卡片标记随之变色；
- **改形状**：圆形 / 方形等形状切换；
- **增加分类**：面板内有「增加」按钮，可添加新分类；
- **删除分类**：删除后该分类下的卡片归入默认分类。

打开 **🧩 功能**，所有进阶工具都在这里：

| 工具 | 说明 |

| 🧵 **伏笔追踪器** | 记录「埋了什么伏笔、在哪埋的、计划在哪回收」，防止挖坑不填 |
| 🕸 **人物关系图** | 记录并可视化人物之间的关系，角色多了也不乱 |
| ✒️ **随机起名器** | 按风格批量生成角色名：古风 / 西幻 / 现代 / 异世界，点击即复制 |
| 📋 **卡片模板** | 人物 / 场景 / 世界观 / 冲突 / 情节 模板，一键打开新建卡片并预填结构 |
| 🗑 **灵感回收站** | 误删的卡片在这里一键恢复；可永久删除或清空 |
| 🌍 **灵感广场** | 看看大家分享的灵感，或把卡片发布到公开广场 |

### 墨匣云阁（同步/备份）

工具栏点 **🏮 墨匣云阁** 打开，所有数据相关操作都在这里：

- **📤 导出备份**：把全部卡片下载为 JSON 文件，存到 U 盘或网盘；
- **📥 导入备份**：从 JSON 文件恢复数据；
- **⏸ 暂停同步 / ▶ 恢复同步**：暂停后改动先攒在本机，恢复后再一起同步；
- **强制重传本机全部**：修复"这台设备有卡、但其他设备收不到"的情况；
- **断开同步**：回到纯本地模式；
- **云端同步设置**：填 Supabase 的 URL、anon key、房间名即可多设备互通。

> 第一次使用云端同步需要去 [supabase.com](https://supabase.com) 免费建一个项目，按配套的配置指南操作即可。

### 热点榜单

右上角 **🔥 热点** 打开热点面板：

- **切换平台**：微博 / 知乎 / 抖音 / 头条，点标签即切换；
- **搜索**：面板内有搜索框，可搜索当前榜单关键词；
- 数据来自公开热点接口，5 分钟缓存，随时刷新。

### 主题与自定义外观

工具栏点 **🎨 主题** 打开主题面板：

- **内置主题**：纸墨、夜幕、黛蓝、青瓷、科幻、古风朱砂、水墨系列、白天浅色等十几种；
- **自定义模式**：自己调色盘底色、卡片色、强调色，还能选图案纹理并调透明度；
- **保存预设**：调好的自定义主题可以存成预设，下次一键切换；
- **自定义壁纸**：可以上传自己的图片或视频当背景，支持自动压缩大文件。

## 数据与隐私

- **默认零上传**：所有卡片、图片、便签、设置都保存在**当前设备的浏览器本地**（localStorage / IndexedDB）；
- **云端同步是可选项**：不配置就永远是本地模式；
- **仓库公开但无数据**：GitHub 仓库里只有程序代码，不包含你的任何创作内容；
- 删卡片先进回收站，误删可恢复；回收站可永久删除。

## 手机当 App 用（PWA）

墨匣是 PWA（渐进式网页应用），手机可以像 App 一样使用：

1. 手机浏览器打开 https://megn206.github.io/moxia/ ；
2. 菜单里选「**添加到主屏幕 / 添加到桌面**」；
3. 桌面出现「墨匣」图标，点开**全屏运行**，体验与 App 一致；
4. 支持**离线打开**（断网也能看已缓存的页面）。

电脑 Chrome/Edge 同样支持「安装应用」，获得独立窗口。

> 提示：手机端与电脑端数据默认各自独立，想互通请配置上面的云端同步。

## 如何更新

1. 我更新功能后，新文件会放到发布包文件夹；
2. 把新版 `index.html` 和 `sw.js` 覆盖到 GitHub 仓库；
3. 等约 1 分钟 GitHub Pages 自动重新构建；
4. 手机/电脑刷新页面即用新版。

> sw.js 已改为**网络优先**策略，换 index.html 即可生效；sw.js 本身变了才会触发浏览器更新 Service Worker。

## 常见问题

**Q：图片存哪里？会占用很多空间吗？**
A：图片压缩后存在浏览器本地（IndexedDB）。删除卡片后图片随之删除；回收站清空会彻底释放空间。上传视频/壁纸时会自动压缩，大文件也能存。

**Q：OCR 第一次用很慢 / 失败？**
A：首次使用需联网下载约 20MB 的中文识别引擎，请保持网络通畅，稍等片刻；之后识别走本地引擎，可离线。

**Q：换了浏览器 / 清了浏览器缓存，数据会丢吗？**
A：数据存在浏览器里，清除该网站缓存/数据会丢失。重要内容建议定期用「📤 导出备份」存一份 JSON，或配置云端同步。

**Q：手机上能同步电脑的数据吗？**
A：配置云端同步后即可互通（见「墨匣云阁」）。

**Q：按钮顺序不喜欢怎么办？**
A：直接按住按钮拖动到你想要的位置，松开后顺序自动保存，下次打开还是你排的样子。

## 技术说明

- **纯前端**：单文件 HTML + CSS + JavaScript，无后端、无数据库依赖；
- **托管**：GitHub Pages（HTTPS，全球访问）；
- **PWA**：manifest + Service Worker，支持安装与离线缓存；
- **OCR**：Tesseract.js（中文简体），识别在本地完成；
- **同步（可选）**：Supabase（PostgreSQL 云数据库，端到端加密可选）；
- **AI（可选）**：内置 AI 续写/扩写/润色功能，可配置自己的 DeepSeek API Key。
